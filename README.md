# Watchlistr web

Watchlistr is a Nuxt 4 web app for discovering movies, shows, and books and saving them to a personal library.

## Stack

- Nuxt 4
- Nuxt UI 4
- Convex
- Auth0
- TMDB and Google Books search

The Convex schema and library functions mirror the Watchlistr extension contract. Both clients use the Auth0 subject as the account identity, so a future shared deployment can expose the same saved library to the web app and extension.

## Local setup

1. Copy `.env.example` to `.env.local`.
2. Use the existing Auth0 SPA application configured for the Chrome extension. Add the web app's local and production origins to that application's Allowed Callback URLs, Allowed Logout URLs, and Allowed Web Origins.
3. Use the same Convex deployment URL and Auth0 issuer/client ID configured for the extension.
4. Run `npm run dev`.

For local development, the web URL is normally `http://localhost:3000`. The extension's callback remains the exact `https://<extension-id>.chromiumapp.org/auth` URL generated by Chrome; do not replace it with a `chrome-extension://` URL. A separate Auth0 application is not required for this shared setup.

Convex code generation requires `CONVEX_DEPLOYMENT` to be set. The generated files are intentionally checked in because the app typechecks against them.

## Validation

```bash
npm run typecheck
npm run typecheck:convex
npm run lint
```

There is no Firebase or legacy content API in this app. Curated content comes from Convex, and provider search is limited to the server-side catalog search endpoint.
